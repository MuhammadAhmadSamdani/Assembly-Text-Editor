# Assembly Text Editor - x86 ASM

**Assembly Text Editor** is a simple **text editor built using x86 Assembly language**. It allows users to create, edit, and manipulate text files with basic functionalities, demonstrating low-level programming for file handling and text processing.

## 🚀 Features
- **Create & Edit Text Files**: Open and modify text documents.
- **Basic Text Operations**: Insert, delete, and navigate within text.
- **File Handling Support**: Save and load text files.
- **Optimized for x86 Assembly**: Lightweight and efficient execution.

---

## 🛠️ Setup & Execution
### **Requirements**
- **Assembler**: MASM, TASM, or NASM
- **Operating System**: Windows (or DOS-compatible environment)

### **How to Run**
1. Install an **x86 Assembly emulator** (e.g., MASM, TASM, NASM, or DOSBox).
2. Load the `Text Editor.asm` file into the assembler.
3. Compile and execute the program.
4. Use keyboard inputs to perform text operations.
